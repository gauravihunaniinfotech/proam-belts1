# Crownworks – Custom Championship Belts (light theme)

Open `index.html` in any browser. No build step. Google Fonts load online (system fonts used offline).

## Structure
- `index.html` – all sections
- `css/style.css` – design tokens (top of file), components, responsive rules
- `js/main.js` – header, reveal, counters, hero picker, accordion, shop filters, spotlight, cart drawer (saved in localStorage), process stepper, testimonials, forms
- `assets/images/` – photos (swap any file, keep the name)

## Notes
- Testimonials, prices, ratings and counts are sample content: replace them with real data.
- Checkout is a demo button: connect your payment provider.
- Some photos show third-party brand logos (559 Fights, Monster, Coca-Cola). Confirm you have rights to publish them or replace them.
